About ANCHOR

ANCHOR is a multi-agent RAG copilot built around a question raised by Deloitte's 2026 Gen Z & Millennial Survey: today's early-career workforce is ambitious but anxious, navigating financial pressure, skill gaps, and uncertainty about AI, while wanting workplaces built around stability, growth, and purpose.

Rather than one generic chatbot, ANCHOR routes every question to one of seven specialist agents, each focused on a single domain drawn directly from the survey's own chapters: financial stability, career pathways, skills, AI readiness, recognition, belonging, and early-career onboarding.

How it stays honest

Every specialist agent answers only from retrieved company policy and primary Deloitte research, never from memory alone. A deterministic grounding check verifies that any specific number or named policy in a response actually appears in what was retrieved, and a separate guardrail watches for signs of real distress and routes straight to crisis resources instead of letting an agent improvise.

Architecture

Employee message → Orchestrator Agent (intent classification) → one of seven specialist agents → shared pgvector store (RAG retrieval) → grounded response generation → deterministic hallucination check → audit log + optional manager nudge → reply.

The seven agents

  • Stability — pay, cost of living, financial hardship policy
  • Pathways — promotion, leadership, career growth
  • Skills — learning, upskilling, certifications
  • AI-Fluency — AI tools, readiness, job-security concerns
  • Recognition — wellbeing, burnout, being seen at work
  • Belonging — purpose, culture, connection
  • Early-Careers — onboarding, first 90 days

Authentication

POST /api/v1/auth/register and POST /api/v1/auth/login issue a JWT. Every request to /api/v1/chat/ and /api/v1/audit/* requires Authorization: Bearer <token> — the employee identity is derived entirely from the verified token, never from client-supplied input.

API

POST /api/v1/chat/ — send {message, session_id?}. Omit session_id to start a new conversation; include it to continue one with memory of prior turns.

GET /api/v1/audit/logs and GET /api/v1/audit/nudges are manager-only and power the Manager Dashboard — every routing decision, guardrail action, and manager nudge is logged with a reason, for full auditability.

Stack

FastAPI · PostgreSQL + pgvector · Groq (Llama 3.3 70B) · sentence-transformers (local embeddings) · SQLAlchemy + Alembic · JWT + bcrypt
